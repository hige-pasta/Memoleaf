# Memoleaf(メモリーフ)

Memo + Memory + Leaf


## アプリ概要

- メモアプリ
- 特徴
  - 短いメモ（leaf）をたくさん残すのを基本とする → メモを簡単に習慣化
    - メモを残すという行動の精神的ハードルを最低限に
    - メモる時間も最小限に
  - メモを見るときは関連したメモ（leaf）を自動でひとまとまりに（tree）
    - 種類、タグ、日付、ワード検索、etc


## 実行環境/使用技術

- Androidアプリ / Webアプリ
- React.js
- React Native


## 仕様


### ポリシー

- 「起動→メモ入力→投稿」の時間をできるだけ短くすることを最優先にする
- 種類やタグ選択もワンタップで
  - 事前設定をしておくことで、メモ記載時にかかる時間を最小にする


### 画面仕様

#### 画面構成

- 左上にページのアイコン
  - Writeページ: leaf.svg
  - Readページ: tree.svg
  - 設定ページ: seed.svg
- 左側にサイドメニュー
  - アイコン押したら表示

#### ページ構成

- Writeページ（メイン）
- Readページ
- 設定ページ

#### Writeページ

- 文字入力フォーム
- メモ種類の選択ボタン（flexボタンで画面に並べる。タップ数が増えるのでドロップダウンにしない。）
- 送信ボタン


#### Readページ

- まずはメモ種類を選択する画面
- アイコン(tree.svg)とメモ種類名が左右でセットになったボタン
- メモ種類によってボタンの色が変わる
- ボタンが縦に並ぶ
  - 選択すると、選択した種類のメモがまとめて整理された形で表示される


#### 設定ページ

- メモ種類を追加する
- メモ種類を削除する
- デフォルトのメモ種類を変更


### メモ種類について

- Writeするときに選ぶ種類のこと


### データ保存について

- データはローカルに保存
- データは暗号化しない


## 必要な画像データ

- ページアイコン用のSVG画像（シンプルでモダンなアイコン）
  - 葉っぱ(leaf.svg)
  - 木(tree.svg)
  - 種から少し芽がでている(seed.svg)

- Androidアプリのアイコン
  - 背景は日焼けした紙をイメージした色。
  - 中央に葉っぱ。色はくすんだ落ち着いた緑。
  - 真ん中に"MEMO"の文字。
  - 全体的にレトロで落ち着いた雰囲気に。ちょっと懐かしい紙のメモを思い出す。
