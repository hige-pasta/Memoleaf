# Memoleaf（メモリーフ）— 機能仕様書

> バージョン: 0.1（プロトタイプ向け）
> 対象プラットフォーム: Web（将来的にスマホアプリへ移行予定）

---

## 1. アプリ概要・コンセプト

### 1.1 コンセプト

- 短いメモ（**leaf**）を素早くたくさん残すことを基本とする
- メモが増えると、関連するleafが集まって **tree（木）** として育っていくイメージ
  - treeはただのリストではなく、集合知・記憶・思い出として可視化される
  - メモの種類によって時系列・重要度・タグによる結びつきなど、最適な形で見せること
- 「メモしたい」と思った瞬間から **投稿完了までのクリック数・時間を最小化** することが最重要

### 1.2 用語定義

| 用語 | 定義 |
|---|---|
| **leaf** | 1件のメモ |
| **tree** | leafの集合。種類・タグ・日付などで束ねたもの |
| **メモ種類** | leafに付ける分類ラベル（例：日記、アイデア） |
| **タグ** | メモ種類とは独立した自由入力のラベル。複数付与可能 |

## 2. 画面構成

### 2.1 ページ一覧

| ページ名 | 役割 | アイコン |
|---|---|---|
| **Write**（メイン） | メモを書いて投稿する | leaf.svg |
| **Read** | 過去のメモをtreeとして閲覧する | tree.svg |
| **Settings** | アプリ設定・メモ種類管理 | seed.svg |

### 2.2 ナビゲーション

- 画面左上にページアイコンを表示
- アイコンをクリックするとサイドメニューが開き、各ページへ移動できる
- アプリ起動時はWriteページを表示する（即メモ開始のため）

---

## 3. Writeページ（メイン）

### 3.1 目的

アプリ起動後、最速でメモを投稿できること。

### 3.2 UI要素

| 要素 | 説明 |
|---|---|
| **テキスト入力フォーム** | メモ本文を入力する。ページ表示時に自動でフォーカスが当たる |
| **メモ種類ボタン** | 種類を1タップで選択。ドロップダウンは使わず横並びボタンで表示 |
| **タグ入力フィールド** | 自由テキストでタグを入力。複数タグはカンマ区切りまたはEnterで追加 |
| **投稿ボタン** | メモを保存する。Ctrl+Enter（Web）でも投稿可能 |

### 3.3 デフォルト動作

- ページ表示時、テキスト入力フォームに自動フォーカス（即タイピング開始できる状態）
- メモ種類は「最後に使った種類」をデフォルト選択した状態で表示する
- 投稿後は入力フォームをクリアし、同じ種類を選択したまま次のメモをすぐ書ける状態に戻る

### 3.4 メモ種類ボタンの仕様

- 設定したメモ種類をすべてボタンとして横並びに表示（flex折り返し）
- 種類ごとに識別しやすいカラーをボタンに適用
- ボタン数が多くなっても1タップで選択できる形を維持する

### 3.5 バリデーション

- テキスト本文が空の場合、投稿不可（投稿ボタンを非活性にする）
- メモ種類が未選択の場合はデフォルト種類を自動選択する

## 4. Readページ

### 4.1 目的

蓄積されたleafを「tree」として俯瞰・閲覧する。

### 4.2 種類選択画面

- Readページの入口としてメモ種類の一覧を表示する
- 各種類はボタン形式で縦並び（tree.svgアイコン＋種類名）
- ボタンの色はメモ種類ごとの色を使用
- 「すべて」の選択肢も用意し、全leafをまとめて見られる

### 4.3 tree表示画面（種類選択後）

種類によって最適な表示形式を採用する。以下は推奨形式（プロトタイプ段階では1形式から実装可）：

| メモ種類の性質 | 推奨表示形式 |
|---|---|
| 日記・日常メモ | タイムライン（時系列リスト） |
| アイデア・発想 | カード一覧 ＋ タグによるクラスタリング |
| タスク | 未完了／完了の2カラムリスト |
| 感想・思い出 | タイムライン or カードグリッド |

> **将来的なビジョン：** メモ数が増えると、タグや日付・内容の繋がりをノード図・マインドマップ的に可視化し、文字通り「tree（木）」が育っていくような表現にしたい。

### 4.4 フィルタ・検索機能

- **タグフィルタ**：タグをクリックして絞り込み可能（複数選択AND/OR）
- **日付フィルタ**：期間指定で絞り込み
- **キーワード検索**：本文・タグを対象としたインクリメンタル検索

### 4.5 leaf詳細・操作

- 各leafをクリックすると詳細表示（本文・種類・タグ・投稿日時）
- 詳細画面から **編集** および **削除** が可能
- 削除は確認ダイアログを1回挟む（誤操作防止）

## 5. Settingsページ

### 5.1 メモ種類管理

| 機能 | 説明 |
|---|---|
| 種類の追加 | 名前と色を指定して新しいメモ種類を作成 |
| 種類の削除 | 既存の種類を削除（その種類のleafは「未分類」扱いにする） |
| デフォルト種類の変更 | Writeページ起動時に最初に選択される種類を固定設定できる（「最後に使った種類」か「固定」かを切替） |
| 表示順の変更 | ドラッグ＆ドロップで種類の並び順を変更 |

### 5.2 初期データ

アプリ初回起動時に以下の4種類をプリセットとして用意する：

| 種類名 | イメージカラー（案） |
|---|---|
| 日記 | 暖色系（オレンジ・アンバー） |
| アイデア | 青系（ブルー・シアン） |
| タスク | 緑系（グリーン） |
| 感想 | 紫系（パープル・ラベンダー） |

## 6. データ仕様

### 6.1 保存方式

- **IndexedDB**（ブラウザ内DB）を使用
- データはローカルに保存し、暗号化は行わない
- プロトタイプ段階ではサーバー同期・バックアップ機能は対象外

### 6.2 leafデータ構造（概念）

| フィールド | 型 | 説明 |
|---|---|---|
| id | string | ユニークID（UUID等） |
| body | string | メモ本文 |
| kindId | string | メモ種類のID |
| tags | string[] | タグの配列 |
| createdAt | datetime | 作成日時 |
| updatedAt | datetime | 最終更新日時 |

### 6.3 メモ種類データ構造（概念）

| フィールド | 型 | 説明 |
|---|---|---|
| id | string | ユニークID |
| name | string | 種類名 |
| color | string | ボタン・表示に使う色（カラーコード） |
| order | number | 表示順 |

## 7. 非機能要件（プロトタイプスコープ）

| 項目 | 方針 |
|---|---|
| **起動速度** | Writeページの初回描画を最優先。重い処理はRead・Settings側に寄せる |
| **クリック数** | メモ投稿までのクリック数を原則 **2クリック以内**（起動→入力→投稿） |
| **オフライン動作** | ローカル保存のためオフラインで完全動作する |
| **レスポンシブ** | スマホ幅（375px以上）でも快適に使えるレイアウトにする（将来のアプリ化を見据えて） |

---

## 8. スコープ外（プロトタイプ対象外）

- ユーザー認証・アカウント管理
- クラウド同期・バックアップ
- データエクスポート／インポート
- 通知機能
- ネイティブアプリ（Android / iOS）対応
- tree表示のノード図・マインドマップ実装（ビジョンとして記載のみ）
